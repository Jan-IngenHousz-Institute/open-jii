# Context

The shared vocabulary for openJII lives in the public glossary at
`apps/docs/content/guide/reference/glossary.mdx`. Use its terms and its scope; do not drift to
synonyms it avoids.

Mobile-only vocabulary is in `apps/mobile/CONTEXT.md`, which predates this file and stays separate
because that vocabulary is genuinely its own.

Architecture decisions are recorded under `apps/docs/content/developers/design-decisions/`.

A term missing from the glossary is a signal: either the project does not use that language, or the
glossary has a gap worth closing there, not here.
