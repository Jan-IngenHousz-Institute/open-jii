Web exports are created per experiment **dataset**, not as one automatic archive
of every table. Choose the table that contains the measurements you need.

## Download a chart image

On a chart with PNG export enabled, use the toolbar's **Download plot as a PNG**
button. The downloaded image includes the openJII logo at the bottom right in a
white footer below the chart. The footer adds height to the image so it does not
cover data, labels, or legends. The chart itself keeps its configured export
resolution and colors. Retrying a chart with fallback rendering keeps the
configured PNG export and logo footer.

This saves an image of the chart. To work with the underlying measurements in
R or Python, create a dataset export as described below. SVG, JPEG, and WebP
exports keep their existing behavior.

## Create an export

1. Open the experiment's **Data** tab and select a dataset.
2. Open **Export Dataset** from the table actions.
3. If needed, choose whether to anonymize contributors for this export. This can
   override the experiment's stored setting.
4. Select a format:
   - **CSV** for spreadsheets and broad compatibility;
   - **NDJSON** for streaming one JSON object per line;
   - **JSON Array** for a single JSON collection;
   - **Parquet** for typed, columnar analysis in Python, R, or lakehouse tools;
   - **Excel** for an `.xlsx` workbook.
5. Create the export. It is queued and prepared in the background, and you get a
   notification when it is ready or has failed, so you can close the dialog meanwhile.
6. Return to the export list and download it when its status is **Completed**.

Each export in the list shows its number, its status (**Queued**, **Pending**,
**Preparing**, **Completed**, **Failed** or **Expired**), its format and when it was
created, with the row count and size once they are known. A failed export says why it
failed. Excel and JSON Array exports, for example, hold at most 1,048,575 rows, so a
larger table has to be exported as CSV, NDJSON or Parquet. The list covers the
dataset's exports by everyone who can open the experiment, not only yours.

A completed export has a download button. A large export is split into several files
of about a million rows each, in row order. **Show files** lists them, each with its own
download, and **Copy all links** copies their links for a download tool. Each download
has to start before the time the list shows, about an hour after it opened. To fetch
every file under its own name, save the copied links as `links.txt` and run
`xargs -n 1 curl -fOJ < links.txt`. If a download stops partway and will not resume,
start it again from **Show files**, which always has fresh links.

CSV and NDJSON files are compressed with gzip and end in `.csv.gz` or `.json.gz`. Python
and R read them as they are; decompress them first to open them in a spreadsheet.
Exports made before this storage existed were carried over as they were, so theirs are
single uncompressed files.

An export is kept for 30 days. After that it shows as **Expired** and can no longer be
downloaded, so create a new export when you need the data again.

## Before analysis

- Keep the experiment ID, table name, export time, workbook version, and protocol
  context with the downloaded file.
- Check row counts and missing values before transforming data.
- Confirm how nested values and raw traces are represented in your chosen format.
- A macro or question field with the same name as one of the table's own columns
  is exported with a suffix: a macro's `device` becomes `device_output`, and a
  question's `date` becomes `date_answer`.
- Prefer Parquet when types and large columnar datasets matter; prefer CSV only
  when flattening and spreadsheet compatibility are acceptable.
- Read the files of a multi-part export together, in the order of their part numbers.
  For Parquet, `pandas.read_parquet` and R's `arrow::open_dataset` both accept a
  folder holding every part.

<Callout type="info">
  Export creation is asynchronous. You are notified when an export is ready, and you can follow it
  in the dataset's export list. Download it within 30 days of its completion.
</Callout>
