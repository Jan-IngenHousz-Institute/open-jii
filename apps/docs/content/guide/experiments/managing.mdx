The **Experiments** page is your home base. It lists your experiments and gives
you a few ways to find the one you want.

![The Experiments overview with the Name column sorted ascending, plus search and contextual create and transfer actions](/img/guide/web/experiments-list.webp)

## Find an experiment

Each experiment is a row showing its **name**, **description**, **status**, **owner**,
owning **organization**, member count, and when it was **last updated**. Select a row to
open the experiment.

Search and filters narrow the list:

- **Search**: type in the search box to match experiments by name and
  description (and by the people and locations linked to them).
- **Status**: pick **Active**, **Stale** or **Published**. Archived experiments
  have their own list.
- **Visibility**: pick **Private** or **Public**.

Each filter opens a checkbox list, and its button shows how many values you picked.
Two values in one filter show experiments that match either; two filters together
show only experiments that match both. **Clear filters** removes every filter and
keeps your search. When nothing matches, the empty list offers the same button. The
filters stay in the page URL, so a refreshed or shared link opens the same view. The
archived experiments list has the **Visibility** filter only.

To change the order, select a column heading. Select it again to reverse the
direction, then once more to return to the default order. Hold Shift while selecting
a second heading to sort within the first column. If you Shift-select a third, it
replaces the oldest choice. The arrows show direction, and a **2** marks the
secondary column. **Reset sorting** clears both choices. Your sort stays in the
page URL, so a refreshed or shared link opens in the same order. The archived
experiments list works the same way.

## Create and transfer

From the top of the Experiments page you can also:

- **Create Experiment** — start a new experiment (see
  [Creating an experiment](/guide/experiments/creating)).
- **Request Project Transfer** — bring in an experiment, its protocols, and its
  data from another platform.

## Archiving

When you are finished with an experiment, you can **archive** it. Archived
experiments move out of the main list into a separate view, which you reach with
**View Archived Experiments**. This keeps your working list focused without losing
anything.
